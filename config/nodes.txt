# nodes.txt — custom nodes installed by provision.sh (git clone, then git pull on
# every later run: that is the update mechanism).
# Format:  git_url|optional_ref|wf:workflow-ids
#   ref  branch or tag to clone (empty = default branch)
#   wf:  workflows that need the pack (ids from catalog.txt). No tag = global.
#        "wf:global,<ids>" installs it for `global`/finish AND for each listed id,
#        so every per-workflow install is complete on its own.
# Requirements are installed with a constraint that keeps the running torch build.
# ComfyUI-Manager ships with the stock template: not listed.
